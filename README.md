# Student Management System

## Project Description
A web-based Student Management System developed using PHP, MySQL, HTML, and CSS.

## Features
- Add new student records
- View all student records
- Edit existing student information
- Delete student records
- Store student data in a MySQL database

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database Setup
1. Open phpMyAdmin.
2. Create a database named `student_management`.
3. Create a table named `students`.
4. Configure database connection settings in `config.php`.

## How to Run
1. Install and start Apache and MySQL using XAMPP.
2. Place the project folder inside `C:\xampp\htdocs`.
3. Open your browser.
4. Visit `http://localhost/DAY20/`.

## Project Structure
- `index.php` — Main page and student records
- `edit.php` — Edit student records
- `delete.php` — Delete student records
- `style.css` — Website styling
- `config.example.php` — Example database configuration
